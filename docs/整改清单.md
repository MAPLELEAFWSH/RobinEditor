> `+layout.svelte` 挂监听；补了侧栏的全局出错通道；`.slot--hot` 高亮加强。
> `pnpm test` 20/20（新增 `tmp/drop-ops.test.mjs` 69 条，做过破坏性试验）、`svelte-check` 0/0。
> 真 webview 里验了槽位标识、高亮 CSS、悬停/离开、合成 PNG 落进去（14×9）、落完清状态；
> **最后从资源管理器手拖一张图，落位正常、像素跟"点选文件"那条路一模一样**（用户实测）。
> 详见 `PROGRESS.md` 的「三、验了什么」和「四、真人手拖也验了」。

**现象**：从资源管理器往窗口里拖图片，没反应。

**根因**：`src-tauri/tauri.conf.json` 里没有 `dragDropEnabled`，而 Tauri v2 这个项**默认 true** ——
Tauri 的原生拖放处理器把文件拦在系统层，webview 拿不到 HTML5 的 `drop` 事件。
全库也没有任何 `onDragDropEvent`，所以那批被拦下来的路径没人接。

**为什么之前没测出来**：上一轮我用 CDP 合成 `File` + `DataTransfer` 派发 drop，
**合成事件不经过系统层**，所以脚本"通过"了而真人拖不动。
这条教训要记住：**验证方法本身要先证明它能复现要验的场景**。

**两种修法**：

| 修法 | 做法 | 代价 |
| --- | --- | --- |
| A | `dragDropEnabled: false`，让 HTML5 拖放正常走 | 一行配置。但前端只能拿到 `File`，`Slots.loadFile` 走 `createImageBitmap` —— **画布解码会改像素**（预乘 alpha，alpha<255 差 ±1、alpha=0 直接抹掉），违反本工程"读像素一律走 Rust `read_rgba`"这条不变量 |
| B（推荐） | 保留 `dragDropEnabled`，前端挂 `getCurrentWebview().onDragDropEvent()`，拿到**真实路径**再走 `loadRef(path)` → Rust `read_rgba` | 要写事件接线 + 判断落到哪个槽；浏览器（dev server）没有这个 API，要留降级 |

**推荐 B**，因为 A 会把像素不变量打破，那个坑这个工程吃过。

**B 的落地要点（照着写，别另发明）**：

- API：`import { getCurrentWebview } from '@tauri-apps/api/webview'`
  （`@tauri-apps/api` 已在 `package.json` 里），
  `await getCurrentWebview().onDragDropEvent((e) => { … })`，
  `e.payload.type` 是 `'enter' | 'over' | 'drop' | 'leave'`，`drop` 时 `e.payload.paths` 是**真实路径数组**。
- 落到哪个槽：建议「当前可见面板里第一个空槽 → 没有空槽就填最前面那个」，
  并把"刚 hover 过的槽"记下来优先用。**别做全局只有一个槽也能用、多槽就乱**的半成品。
- 路径 → `FileRef`：`loadRef(path, ref)` 要 `{ path, name, rel, ext, size }`。
  `name`/`ext` 有现成的（`io.baseName`）；`rel` 用 `baseName` 就够；
  **`size` 现在没有现成的取法** —— `fsops::file_exists` 在 Rust 侧注册了但 `io.ts` 里没包，
  要么顺手包一个 `stat`，要么 `size` 填 0 并确认界面上那一格不会显示成 `0 B` 这种假信息。
- 拖进来时给个视觉反馈（复用现有的 hover/拖放样式，别新造一套）。动效数值只从令牌取。
- **浏览器（dev server）里没有 `getCurrentWebview`**，要 try/catch 降级到 HTML5 拖放，
  否则 `pnpm dev` 里调试时拖拽直接报错。
- 改完 `tauri.conf.json` 不用动（保留原生拖放）。

**怎么验**：这一条**脚本验不了** —— 真拖放走系统层，CDP 合成事件不经过它。
只能：起 `pnpm tauri dev` → **人手从资源管理器拖一张图进去** → 看槽位有没有填上、
像素对不对（拿一张 alpha<255 的图，跟"点选文件"那条路的结果比，必须一模一样）。
**人手验完把结论写进 PROGRESS，别写"应该好了"。**
