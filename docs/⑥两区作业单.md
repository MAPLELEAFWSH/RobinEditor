## 二、两个区（分工明确，能合着用的代码就合着用）

### 区 1「修复工程」
用户原话：**"有文件缺失检索不到就抛异常，正常情况修复好了打开正常，也适用于工程文件移动位置后修复，
顺带展示定位的位置可以单选或多选改变选中的文件"**。
- 检索不到 → **抛异常**（明确报错、逐条列出，不许静默、不许猜）；
- 正常情况 → 修好后 **MMD 打开正常**（已在香港夜间那套上由用户实测："可以开、齐全、不弹"）；
- **工程文件移动位置后的修复**同属这一区；
- **表里展示"定位到的位置"，并支持单选 / 多选后一起改**（勾选若干行 → 统一指定/改变）。

### 区 2「打包迁移」
用户原话：**"识别工程所包含文件和工程文件一起打包到指定位置，顺带处理好让工程打开就正常"**。
- **识别工程包含的文件**（模型/贴图/特效/附件/（动作内嵌在工程里））+ **工程文件本身**
  → **一起打包到指定位置** → **处理好路径，让工程打开就正常**（自包含）。
