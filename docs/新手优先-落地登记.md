## 走查里找出来并修掉的问题（4 条）

1. **① 日文「文件」分区的主按钮在参数抽屉里**（抽屉默认收起 → 新手扫完目录找不到"跑"）→ 搬进主区 `.wb__acts`，「选目录」降为次级。
2. **① 拖文件夹会跳页** → 改成就地列清单（§四 不跳页）。
3. **ikClut 主按钮叫「导出 1024×32」** → 「导出 CLUT」（动词+对象）。
4. **ikClut 一屏 20 个控件** → 收到 4 个（存快照对比收进展开区；`Preview` 的缩放条收成一行 `视图 100%`）。
