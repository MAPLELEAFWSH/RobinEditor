# ② 调色 —— 作业规格

用户 2026-09-20 原话：**"调色要 LUT 的可以导入 LUT，可以有基础调色、色轮、曲线、色彩变形、HSL、节点、LOG/HDR 色轮"**，
并在定顺序时选了 **③④⑤ → ① → ② → ⑥**。这是那一大块重做。

## 0. 现状

`src/lib/modules/ikclut/`：烘焙 1024×32 的 CLUT 给 ikClut 用，能混几张现成 LUT。
参数只有曝光/对比/饱和/色相 + 三条 RGB 曲线（`img.ts` 的 `GradeParams`）。
**没有**：导入 LUT、色轮、HSL、色彩变形、LOG/HDR、处理链。预览走 `applyClut`（1024 封顶，实测 29.9ms）。

## 1. 要做的东西

1. **导入 LUT**：`.cube`（1D/3D）。解析、校验（尺寸、DOMAIN、行数），存成现有的 `Clut` 结构。
   导入的 LUT 直接作为链上的一个节点参与，也能跟烘出来的表混。
2. **基础调色**：曝光 / 对比 / 饱和 / 色相 / 色温色调 / 高光阴影 / 黑白点（在现有四个之上补）。
3. **色轮**：暗部 / 中间调 / 高光三个轮（色相 + 强度）+ 全局轮 + 整体偏移。
4. **曲线**：RGB 三条 + 亮度 + 可选单通道细化（现在只有三条 RGB）。
5. **色彩变形（color warp）**：色相 vs 饱和度 / 色相 vs 亮度 两个二维网格，拖点变形。**这是最贵的一项，最后做。**
6. **HSL**：8 个色相段（红橙黄绿青蓝紫品）各调 色相偏移 / 饱和 / 亮度，带段间平滑。
7. **节点**：**先做成"可增删、可重排、可单条开关的处理链"**（一条链就是一套处理步骤）。
   自由连线的节点图**不做**（收益不确定、返工面极大）—— 要做另开一轮。
8. **LOG / HDR 色轮**：LOG 轮（在 log 空间调色，进出各一次转换）+ HDR 轮（>1 的亮度范围）。
   转换只做自己实现的那几种（不要引入第三方色彩库），并把"哪个游戏/哪套片场用什么曲线"留成可选。

## 2. 架构（照本工程的老规矩）

- **纯逻辑进 `ops.ts`，不碰 DOM**，`$derived` 只在界面层。现在 `GradeParams` + `applyGrade` 在 `img.ts` 里，
  链一长就不该继续堆在那儿 —— **把调色链拆成 `src/lib/modules/ikclut/grade/` 下的若干纯函数**，
  `img.ts` 那两条保留（ikClut 烘焙那条路还在用），**不许出现第二套等价的 applyGrade**。
- **预览**：整链跑在预览尺寸上（上限沿用 `预览长边(1024)`，实测依据在 `tmp/preview-cost.mjs`），
  拖滑杆时按帧节流；**导出**按原尺寸重算，预览与导出必须走**同一个函数**（不许两套实现，
  否则"打回去颜色不一样"就查不出来）。
- 每个节点一个独立的纯函数 `(ImageData|Clut, 参数) => ImageData|Clut`，能单独测。

## 3. 验收

1. 每个节点至少有单测：恒等参数下**逐字节不变**（这是最省事又最能抓错的一条）。
2. **链的顺序有意义**：`A→B` 与 `B→A` 结果不同（挑一对证明），否则说明链是假的。
3. **导入 LUT**：`.cube` 解析有测试（含 1D、3D、DOMAIN 非 0~1、行数不符要报错）；
   导入的 LUT 用在一张已知图上，结果与手工算法一致。
4. **LOG/HDR**：进出转换往返误差有断言（`log → 调 → 还原` 在恒等参数下应当近似恒等）。
5. 预览与导出**同函数**：测试里断言导出走的就是预览那条链（源码级或调用级都行）。
6. 基线全绿：`pnpm test`、`cargo test --lib`、`svelte-check` 0 错 0 警。
7. 性能：4K 原图跑整链要报出耗时（`tmp/preview-cost.mjs` 同款量法），超一帧预算的节点要标出来。

## 4. 边界（硬规矩）

- **不许起任何 GUI 窗口**（用户全屏游戏时被弹窗打断过，已明令禁止）；验证全走命令行。
- 文本文件只用 read/edit/write 工具改；**绝不用 PowerShell 的 `Set-Content`/`Out-File`**。
- `实战测试用例\` 原始素材**只读**，产出写 `实战测试用例\测试效果\`。
- 不引第三方色彩/调色库；实现只按公开格式（`.cube` 是公开格式）与本工程实测。
- 不搬任何第三方工具的代码、注释、界面文案、操作方式。
- 注释和界面文案按"开发者自己的简短笔记"写，不辩论、不解释设计意图。
- 一步做完一步：**先"导入 LUT + 基础调色 + 曲线"能跑通并全绿，再往上加**色轮 / HSL / LOG / 变形 / 链。
