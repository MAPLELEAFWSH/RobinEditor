# 使用说明（新手向）

这份是给第一次打开 RobinEditor 的人看的。看完你应该能自己把一套 MMD 模型和它的贴图处理完。
每个功能**怎么用、什么时候用、坑在哪**都写了；界面上的字和这里对得上。

不想看长文的话：`dist\说明.txt` 是七个功能的短版（那份是打包时生成的，要等下次重编才跟得上）。

---

## 一、先搞清这个工具是干嘛的

它不渲染、不出图、不能替代 MMD。它只做一件事：**把模型和贴图整理成渲染包要的样子**。

所以它的用法永远是这三步：

1. **告诉它素材在哪**（模型目录、贴图、渲染包目录）
2. **挑一个功能跑一遍**
3. **它把结果写回你指定的地方**

它不改你的原文件（除非你让它原地改，那也会先留 `.bak`）。

---

## 二、第一次打开，做两件事

**第一件：把渲染包的位置指过去。**
各功能页里各自选：③ 那页顶部的「选 Ray 包目录」（也可以把文件夹拖上去）、
⑥ 那页的模板目录、② 那页的 ikClut 目录。
本工具**不内置**这些包，也不带任何渲染器 —— 它只是去你给的那个目录里读写文件。
（左边原来那条「设置」2026-10-07 删了：那一页是占位，什么都改不了。
能调的是**右下角那个悬浮球**打开的外观面板：主题色相、壁纸、各层不透明度、动效、翻译引擎。）

**第二件：选一次模型文件夹。**
选过（或者拖过）一个目录，**顶栏那颗「当前工程」**就会显示它，切到别的功能页也不会变。

> 桌面版（装的那个 exe）能解析 PMX、能读写任意路径。
> 浏览器里跑（开发模式）只能看界面和拖图，PMX 解析走不通 —— 界面会写一句提示，别以为是坏了。

---

## 三、界面就三块，不用记

- **左边一列**：所有功能，按组分的。点一个进去。
- **顶上一条**：进了功能之后，这条是它的**分区**（一个功能往往分几页，比如 ⑦ 有九个分区）。
- **底下一行**：出错和状态。**报错永远出现在这里**，不弹窗。看到了先看这一句。

每个功能页基本都是同一个形状：**左边放素材、中间看结果、右边调参数**。

## 四、七个功能，各管一件事

### ① 日文乱码修复

**什么时候用**：打开渲染包的 `readme` 或者 `.fx`，日文全是「縺ゅ＞縺」这种乱码；
或者乱码修好了、但你只想看中文。

**第一步 · 还原（不联网）**：选一个文件、把内容贴进来、或者整个目录丢给它，
它自动认编码（Shift-JIS / EUC-JP）还原成日文。`.fx`/`.fxsub` 走「只动注释、代码一个字符不碰」那条路，
其余文本整篇算。这一步和「批量」那两页**永远不联网**。

**修不出来也不会把乱码丢回给你**：有一类乱码（短的、假名和汉字混排的）它不敢自动改 ——
那种情况它会把那一段连同**候选、增益、以及为什么没自动改**一起列出来，
你看哪条对就点「就用这个」，点了才动那一段（`.fx` 里也只动注释）。
只有**一条候选都没有**的时候才算真修不了。

**名字也是乱码的情况（「名字还原」那一页）**：下载来的渲染包里很常见 ——
文件内容好好的，文件名/目录名是乱码（`00_僔僃乕僟乕傪嵞攝晍偡傞偲偒偺拲堄揰.txt` 这种）。
选目录 → 它把「原名 → 修后名」列成一张表 → 勾选后改名。
**不覆盖同名**（目标已存在就跳过并说明），改完能整批回滚。
默认只勾"有把握的"；没把握的（比如你自己起的中文名）也会列出来，但要不要改得你一条条看。

**第二步 · 翻成中文（可选，默认关）**：
**默认引擎是 MyMemory**（免费公开接口，**不用填任何东西**）—— 打开那个开关就能用。
免费服务有**每日额度**，用满了它会回一句"今天的免费翻译用完了"（原话会摆出来），那就要等明天或换引擎。
想换成自己的引擎：右下角「外观」面板最下面「翻译引擎」选「自定义」，填地址、模型名、Key。
地址填 OpenAI 兼容的那种，本机 Ollama 就是 `http://127.0.0.1:11434/v1`，填完按「试一下」，
它会真发一句短句并**把译文或原始报错摆出来**（401 是 Key 不对、404 多半是末尾少了 `/v1`、
连接被拒是本机服务没起）。
然后在 ① 那一页把「再翻成中文」打开 → 点「翻 N 段」→ 三栏对照（原文乱码 / 日文 / 中文），
**中文那栏能直接改**，模型翻歪的地方自己修 → 「另存」（默认加 `_zh` 后缀）或「原地写回」（留 `.bak`）。

**只发注释正文**，代码一个字符都不发；写回时也只替换注释正文，代码行与原文逐字节相同。
翻了中文就只能按 UTF-8 存 —— 原来的日文编码装不下中文。

**离线那条路**：把引擎选成「离线」就用它 —— 那是把固定说法换成中文，
**不是翻译，句子不会翻**（界面上就这么写着）。

**坑**：一次最多扫 400 个文件，超出的部分界面上会写"还剩多少没碰"。
请求只在你自己打开那个开关时才发；**还原乱码那一步永远不联网**，整页离线也能用。

### ② ikClut 调色

**什么时候用**：想让整体色调偏一点（冷暖、曝光、对比、曲线），又不想在 MMD 里逐帧调；
或者手上有一张现成的 `.cube` LUT 想直接用/掺着用。

**怎么用**：把参数调好 → 导出那张 1024×32 的 CLUT 图 → 把这个图喂给 ikClut。

**参数是"一条链"，从上往下跑**（右边「处理链」那一栏）：

- **基本**：曝光 / 对比度 / 饱和度 / 色相 / 色温 / 色调 / 高光 / 阴影 / 黑点白点。
  色温往正走偏暖（提红压蓝），色调往正走偏品红；高光阴影按**亮度**加权，不改色相。
- **曲线**：RGB 三条 + **亮度**一条 + **第四条自选通道**（下面那排按钮定它作用在 R/G/B/亮度）。
  亮度那条是按比例缩放三条通道，不动色相。插值方式（线性/平滑/阶梯）四条共用。
- **导入的 LUT**：`.cube` 的 **1D 和 3D 都能读**。读进来的表**按原精度**参与这条链
  （不是先压成 32³ 再用），右边「掺多少」能在原色和整张表之间插。
  3D 的排法、`DOMAIN_MIN/MAX`、行数对不对，读的时候都会校验；读不了会明说是哪儿不对。

**顺序是有意义的**：先曝光再拉曲线，和先拉曲线再曝光不是一回事 —— 所以链能**上移下移**、
能**勾掉某一条**、能**加/删**。同一类节点现在只能放一个。以后要加的（色轮 / HSL / LOG-HDR /
色彩变形）先不做，界面上列着。

**拖动时预览是粗的**：链一长，1024px 的预览一帧要 60ms 上下（粗图 512px 只要 15ms），
所以**拖动时按 512 算、停手 0.25 秒后自动补一张 1024 的细图**。自检也一样，停手后才算。

**怎么知道没错**：「自检」那一栏把烘出来的表打回原图、和直接跑这条链的结果比，
差值只来自 32³ 的量化与三线性插值 —— 两边跑的是**同一段代码**（烘表就是拿链跑一遍采样网格）。

**混合页**：手上已有几张 LUT 想混成一张，选 1 / 2 / 4 张、给个混合位置就行。
那一页也能**直接导入 `.cube`**（会先摊成 32³ 再进混合，因为 ikClut 只认 32³）。

**导出**：除了 CLUT 图，还会在同名 `.txt` 里写下**整条链**的每个节点参数（含导入的表名与强度），
过一阵子回头看就知道这张表是怎么来的。

### ③ Ray 编辑器

**什么时候用**：想关掉 Ray 包里的某个效果（阴影、雾、水面反射），但 ray.conf 里几百个 `#define` 找不到。

**怎么用**：把 Ray 包目录拖到工具条上（或者点「选 Ray 包目录」），它把开关做成列表。
改完**先给你看 diff**，确认了才写盘，写之前留 `.bak`，写完还会读回来核对一遍。

**顺手**：贴图路径那一行可以直接把文件拖上去；它会把路径改成相对路径，并自动把同组的 `FROM` 拨成 1。

### ④ msToon 贴图

分五页。**默认那页最常用**：

**什么时候用**：手上有一张模型自带的 lightmap，想让 msToon 认。

**怎么用**：选游戏（原神 / 星铁 / 绝区零）→ 把 lightmap（绝区零是 `_M`）丢进去 → 导出。
出来的是一张打包好的控制图，连同一份"怎么重来一遍"的说明一起写出去。

**后面四页**（ShadowRate / SubLightRate / EdgeRate / FaceSDF）是手画那四张控制图的：
四路各挑一个来源（取哪一路 / 按分布配 / 填常量），下面实时看结果。

> 这四个页面的参数**按游戏各存一套**，切游戏就换一套，关掉再回来还在。
> 它们在三渲二渲染里本来就是每游戏一套；不过这三张图**模型库里没有每游戏的实测样本**，
> 所以存的是**你自己调的值**，界面上会标「你存的这套 / 还没调过」。

**FaceSDF 那页有个坑**：星铁那张脸图 R 通道是三档（0 / 0.5 / 1），
中间那片 0.5 是作者按脸部结构画的，算法推不出来。要画它，就得自己标一张遮罩丢进「0.5 区」那一格。

### ⑤ 绝区零贴图合成

**什么时候用**：要把绝区零的 `_A` / `_M` / `_N` 三张拼成一张 LM。**只管这一个游戏的这一种排法**
（原神 / 星铁那两套排法已经不在这页了）。

**怎么用**：三张丢进去 → 导出 LM。「从目录自动配对」会自己认文件名把三张配好。
通道怎么取不用你记，界面右边写着（R 取 `_A` 的 G、G 取 `_N` 的 B、B 取 `_M` 的 B、A 填 1）。
「配对检查」那页是拿材质名对着磁盘核一遍，看哪张贴图少放了。

### ⑥ 养乐多上材质

**什么时候用**：想让模型走养乐多的 MME 材质，但 PMX 里几十个材质要一个个手填贴图路径。

**怎么用**：模型目录拖到卡片上（或者点「选模型目录」）→ 它按材质名分类，照模板填好路径和参数，写出 `.fx`。

**注意**：生成的是**起手参数，不是成品效果**。子材质槽位顺序读不到，只能按材质顺序排。
贴图那些输入框可以直接拖文件进去。

### ⑦ 贴图通道处理

九页，最常用的是这两页：

- **「通道提取」**：丢一张图进去，它把 R / G / B / A 四路摊开，认语义（粗糙度、金属度、
  高光那些）也认材质 ID，按需要拆成遮罩导出。
  顺手还会告诉你**这张像不像法线、是哪一种**：已经是标准蓝（不用动）、B 不是 z（要重建 Z）、
  B 是空的（RG 双通道）、R 恒定且数据在 A（AG 打包，粉色）。

- **「批量」**：整个目录一起跑（拆通道、取某一路当灰度、法线重建 Z、跑调整、套图层…），
  子目录结构保留。

其余的页（分离合并调换、图层与蒙版、调整、混合）都是"想单独改某一步"的时候才用。

**法线那件事**（2026-10-07 加的）：「调换」和「合并」里 B 那一路能选
「由 R、G 推 Z」—— 三路会一起重写成标准蓝法线。预设里三条：
法线·重建 Z、法线·翻绿（DirectX ↔ OpenGL 方向反了就用它）、AG 打包 → 标准蓝（粉色那种）。
侧栏还有一档**放大核**：法线、材质 ID、遮罩这类数据贴图用**最邻近** ——
双线性会插出中间值（实测一张 4 种材质的 ID 图会变成 13 种）。

> 「分块定档」这一页 2026-09-24 由用户决定删掉了（连它的算法、画笔、量具和三套守卫一起）。

## 五、几个通用的做法

**拖进去比点按钮快。** 图、`.fx`、文件夹，能拖的地方基本都能拖：
图片槽、贴图输入框、渲染包目录、模型目录。拖对了那一格会亮起来。

**导出前它会问你选目录**（桌面版）。选一次之后就一直在那儿，直到你关掉这个页面。
不想选就直接关掉那个框，它什么都不会写。

**图大就等一会儿。** 4096² 的图做全尺寸合成要几秒，这时候按钮会变成「算中…」——
它在算，别重复点。

**看结果。** 大部分页左边是"放素材"、中间是"出什么"，右下角那行是报错。
有一条要注意：**报错超过 9 秒会自己消失**，也可以点旁边的叉关掉，换页也会清。

## 六、出问题了先看这几条

| 现象 | 多半是 |
| --- | --- |
| 拖进去的图没反应 | 格式不在认得的列表里（png/jpg/tga/bmp/gif/webp/tif/dds/ico），换一张试试 |
| 面板看着是空的 | 有些页面**没放素材时不渲染调参数的界面**，先把图丢进去 |
| 选目录、解析 PMX 点不动 | 你在浏览器里跑，不是桌面版 |
| 导出的图跟预期不一样 | 先确认**按谁的约定画**选对了（⑦ 那一页），通道含义选错会整张错位 |
| 界面上的字跟这份说明对不上 | 说明和界面都可能更新，以界面上写的为准；这份有出入就报一下 |

## 七、这个工具不做什么

- **不含、不分发**任何渲染包和别人的工具。Ray、养乐多、ikClut、msToon 都得你自己装，路径自己指。
- 不会自动帮你"猜"出贴图该怎么画。它能做的是**把选区、档位、导出这三步变快**，
  以及按实测数据给出起手值 —— 判断还是你的。
- 跨模型套用的规律不提供（实测是负收益）。它不提供"照着别的模型猜"这种按钮。
