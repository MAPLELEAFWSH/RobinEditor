# ⑥ 工程迁移 —— 两种情形的方案（用户 2026-09-22 定案；实施记录见 `docs\⑥工程迁移-模块行为.md`）

用户 2026-09-22 口述（原话逐条对应）：

> 1. **工程修复**：做完工程但是工程文件移动位置导致工程需要挨个重新导入文件处理，就要导入工程 pmm 和 emm 文件，
>    让其**检索移动后的文件的位置**、**重新定向**，让工程正常打开不用挨个导入；
> 2. **工程迁移打包**：要迁移工程把 **pmm、emm 和工程文件一起打包**好放在一个地方；接收这种打包后通过处理，
>    让使用者**下载别人的打包工程后**这样处理：把工程**存放到指定位置**，或**分别将文件存放在不同的位置**后
>    **重新定向**正常使用；
> 3. **两者都要支持对应工程内的 VMD 一起成功载入。**

## 一、情形 1：工程修复（文件被挪走 → 检索 + 重新定向）

已经做出来的部分（可直接用）：拖 `.pmm` → 自动接 `.emm` → 出表 → **按旧根→新根批量** / **逐条指定** →
写盘（回读核对：新路径在、旧路径归零）。香港观塘夜间那套实测通（与用户拖进 MMD 不弹框的那份逐字节相同）。

**检索这一步已经做出来了**（用户原话"**让其检索移动后的文件的位置**"）：
- 给定**一个或几个搜索起点目录**，按**文件名**（+ 后缀）在整棵树里找缺失的那些文件；
  找到唯一匹配就自动填上，找到多个就**列候选让人挑**（不给自动建议）；
- 搜索**可以多选目录**（模型可能被挪到 A 盘、特效被挪到 B 盘）；
- 在测试/临时目录里搜到的候选降级成"待确认"（产品不许把量具的临时目录当成用户素材）；
- 找到之后仍然走"改路径 → 回读核对 → 写盘"这条既有链路，**没有第二条写盘路**。

## 二、情形 2：工程迁移（打包 → 传输 → 落地重定向）

分三段，每段都要能单独用：

**① 打包（在我这边）**：把 `pmm` + `emm` + **工程引用的全部文件**（模型 `.pmx/.pmd`、贴图、特效 `.fx/.fxsub/.x`、
附件）按**保留相对结构**的方式拷进一个目录 —— 这就是**自包含目录**：
"**打包工程所有需要的文件到指定位置，并可以正常打开使用**"。
（照参考项目那个"导出包"范式：**先预检（缺文件就列出且不产出）→ 临时 staging 组装 → 包内路径改相对 →
重名时自动选唯一目录**。这套做法参考项目里有，本工程按自己的实现写；实测 1980 文件 / 361.1 MB / 172 条路径全指包内。）

**② 传输**：用户自己压包/发人（工具不管网络）。

**③ 落地（在接收方）**：解开后两种用法**都要支持**，各对应一条已有的路：
- **放成一个位置**：整个目录丢到某处 → **A 原地修复**（根替换）把工程里的路径重新定向到这个位置；
- **分别放到不同位置**：模型放一处、特效放一处… → **C 搬运**（把文件真的搬/拷到多组目标）或
  逐条指定 + **B 检索**把它们找齐。
- 用户 2026-09-22 明确要的正是这一条："把工程**存放到指定位置**，或**分别将文件存放在不同的位置**后重新定向正常使用"。

## 三、VMD（两种情形都要支持）

**这一块已经量过了**（见格式规格 §30 一线与 `docs\⑥香港验收-结果.md`）：

- 363 个 `.pmm`/`.emm` 里**一处 `.vmd` 引用都没有** —— 工程里没有"VMD 路径"这个字段可改；
- 动作数据是**嵌在 `.pmm` 的模型帧区里**的（香港夜间那套里 114 处插值模式 `14 14 6B 6B`）；
- 所以"工程内的 VMD 一起成功载入"实际等于 **不许碰帧区**，不是"还要改一处 VMD 路径"。
  保证方式：写盘后**所有差异字节必须落在被改写的 256 字节路径字段内**，另有专门单测钉住。

## 四、界面上要体现的（新手友好）

- 一进来就分**"你是哪种情况"**：`文件都在`（A/C）/ `做成自包含目录`（D）—— 只显示该走的那几步；
- 默认把能自动推断的都填好（旧根、新根、搜索结果），**人只需要确认或改个别条目**；
- 每条路径**就地可编辑**（不只"用这个"）；
- 全表**没有"未落定"条目**才允许写盘；写盘前**预检**，缺文件就逐条列出且**不产出**；
- 路径**一律换行显示、不省略、不许重叠**（用户报过"看不完整"和"重叠冲突"）。

## 五、四个入口（用户已拍）

1. **检索的入口**：给**一个/多个"搜索起点目录"**让工具自动找（模型在一个盘、特效在另一个盘是常态）——
   产品里就是"⑤ 找不到的，让工具去搜"那张卡上的"加搜索起点…"。
2. **打包的形态**：**一个目录，不压缩**。不做 `.zip`（用户没要，压不压是用户自己的事）。
3. **VMD**：见 §三 —— 实测不存在引用，结论是**不碰帧区**。
4. **接收方的第三步**：**两种都要** —— "指定一个新位置就完事"走 A；"逐个文件指"走逐条指定 + B。
