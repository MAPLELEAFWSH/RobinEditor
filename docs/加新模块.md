# 怎么加一个新模块

模块注册表在 `src/lib/modules/registry.ts`。**加一个功能只需要改这一个文件**
（要自己画界面的话再加一个 `.svelte`）。

以前加功能要同时改 `nav.ts`、`panels.ts` 和功能页三处，漏一处就会出现
"导航里有、页面打不开"这种半成品。现在导航树、分区 Tab、功能页标题、
关于页的"已做好 / 排在后面"清单全部从注册表派生，不可能对不上。

---

## 一、最小情况：只要一个占位的功能页

往 `MODULES` 数组里加一条：

```ts
{
  id: 'newthing',          // 路由后半段，对应 /tools/newthing
  no: '⑨',                 // 需求里的原始编号。工作区类的模块不写
  name: '新功能',
  desc: '一句话说清它是干什么的。功能页标题下面、导航 title 都会用它。',
  group: 'texture',        // 属于哪个分组，见下面的 GROUPS
  icon: 'leaf.ikclut',     // icons.ts 里的键
  ready: false,            // false 会在导航里挂"待做"角标
  panel: 'main',           // 默认打开哪个分区
  order: 4,                // 组内排序
  panels: [
    { id: 'main', label: '主界面', hint: '半句话说明' }
  ]
}
```

保存即可。导航、功能页、关于页全都自动出现，不用动别的地方。

分组只有这五个（`GROUPS`）：

| id | 名字 | 放什么 |
|---|---|---|
| `work` | 工作区 | 总览（「最近工程」「快捷动作」两页 2026-10-07 删了） |
| `texture` | 贴图 | 通道处理、ILM（④ msToon 已删，号不补） |
| `grade` | 调色 | ikClut |
| `text` | 文本 | 乱码修复 |
| `render` | 渲染联动 | Ray、养乐多 |

要开新分组就往 `GROUPS` 里加一条（`order` 决定它在侧栏里排第几）。

## 二、要自己画界面

**一个模块一个组件**，组件内部按 `panelId` 切分区。分区 Tab 仍然由注册表驱动，
组件只负责画内容 —— 这样换分区不会重建组件，状态能留住（切回曲线页时
曲线还在，不会被打回默认值）。

```ts
import Newthing from './newthing/Newthing.svelte';

panels: [
  { id: 'main', label: '主界面', hint: '半句话说明', component: Newthing },
  { id: 'extra', label: '另一页', hint: '同一个组件，换 panelId', component: Newthing }
]
```

组件签名固定是这样（`WbProps` 在 `src/lib/modules/wb-props.ts`）：

```svelte
<script lang="ts">
  import type { WbProps } from '$lib/modules/wb-props';
  let { panelId = 'main' }: WbProps = $props();
</script>
```

功能页会传 `panelId={cur}` 进来，你在组件里 `{#if panelId === 'main'} … {/if}`。

照着 `src/lib/modules/channels/Channels.svelte` 写 —— 那是参考实现，
结构、注释口气、CSS 习惯都照它。

### 现成的东西，别重造

| 要什么 | 用哪个 |
|---|---|
| 图片槽（点选 / 拖入 / 换 / 清） | `$lib/components/wb/Slot.svelte` |
| 槽位状态（加载、预览 URL、错误） | `$lib/wb.svelte.ts` 的 `Slots` 类 |
| 提示条 | `$lib/components/wb/Note.svelte` |
| 文件选择 / 目录扫描 / 读图 / 写盘 | `$lib/io.ts` |
| 像素运算（拆通道、打包、缩放、曲线、LUT、Sobel、距离场） | `$lib/img.ts` |
| 两栏版面、行、滑杆、勾选、分段选择、图片槽、预览台、表格 | `src/styles/wb.css` 里的全局类 |
| 打开外部链接 | `$lib/open.ts` 的 `openExternal` |

`wb.css` 里已经有：`.wb .wb__main .wb__side .grp .row .range .chk .pick
.slots .slot .chip .stage .note .kv .list .strip .acts .mini .mono .h3 .pad`。
能用这些就用，**别每个功能各写一套滑杆和图片槽** —— 那样用起来会像八个不同的软件。

设计令牌全在 `src/styles/tokens.css`：`--fs-*` 字号、`--t-*` 时长、`--lift-*`
抬起幅度、`--z-*` 层级、`--r-*` 圆角、`--a-*` 各层不透明度。
颜色跟着 `--hue` 走，别写死。

图标用 `<Icon name="ui.import" size={16} />`，名字见 `src/lib/icons.ts`。
需要新图标就往 `tools/build-icons.mjs` 里加一行再跑 `pnpm icons`
（界面图标取 Material Design Icons，品牌图标取 simple-icons）。

### 需要后端能力的时候

前端干不了的事才往 Rust 里放，目前分了三个模块：

- `src-tauri/src/fsops.rs` —— 目录扫描、图片解码（TGA/DDS 这类 canvas 不认的）、
  按原路径写盘并留 `.bak`
- `src-tauri/src/textenc.rs` —— GBK / Shift-JIS 转换（`TextEncoder` 只有 UTF-8，
  编不回 GBK，所以这段只能在 Rust）
- `src-tauri/src/pmx.rs` —— PMX 二进制解析

加命令的步骤：写 `#[tauri::command] pub fn 你的命令(...)`，然后在
`src-tauri/src/lib.rs` 的 `generate_handler!` 里登记，最后在 `src/lib/io.ts` 里
包一层带类型的封装（别在组件里直接 `invoke`，参数名约定会散得到处都是）。

参数名注意：**Rust 是 snake_case，JS 侧要写 camelCase**。
`rgba_b64` 对应 `rgbaB64`，`material_limit` 对应 `materialLimit`。

验证后端别只靠 svelte-check —— 类型检查看不出运行时。两条路：

```powershell
cargo test --lib                  # 纯函数（编码、PMX、路径）的单测
node tmp/cdp.mjs tmp/xxx.js       # 在真 Tauri webview 里跑，连真文件一起验
```

第二条要先 `pnpm tauri dev` 并且带上
`$env:WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS='--remote-debugging-port=9222'`，
`tmp/cdp.mjs` 会连上去执行一段 JS。浏览器里的 dev server 没有
`window.__TAURI_INTERNALS__`，调不到 Rust。

## 三、几条硬规矩

1. **层级只用 `--z-*`**。全站的层叠顺序在 `tokens.css` 里排好了：
   壁纸 -2 < 内容 1 < 顶栏 40 < 侧栏 50 < 尾栏 60 < 悬浮球 70 < 面板 80 < 模态 90 < 开场 100。
   就地写 `z-index: 999` 迟早会压住别人的东西。
2. **贴底/贴边的元素要按令牌让位**。尾栏高是 `--status-h`，球列高是
   `--fab-stack`。设置面板的 `bottom` 就是这三项算出来的；
   写死数字会让它们各自漂移、互相压住（参考项目专门记录过这个坑）。
3. **动效数值只准从令牌取**，别就地写 `transition: all .3s`。
   见 `docs/动效口径.md`。
4. **文案写成人话**：不出现"一键 / 极致 / 赋能 / 打造 / 一站式"，
   不用破折号做插入语，不写"本页的定位是……"这种自我说明。
   注释写开发者自己记笔记的口气，只陈述约束，不辩论。
5. **颜色不要写死**。跟着 `--hue` 走的用 `oklch(L C var(--hue))`，
   分隔线和次要文字用中性 rgba，语义色（`--ok` / `--warn` / `--danger`）色相固定。
6. **不做彩色光晕 / 发光 / ring**。悬停只做小位移加阴影。这条是被明确要求过的。
7. **不要用 PowerShell 改文本文件**（`Get-Content` / `Set-Content` / `-replace`）。
   它会把 UTF-8 读成 ANSI 再写回去，整个文件的中文全废。改文件只用 `read` / `edit` / `write`。
8. **改完跑 `pnpm check`**，必须是 0 error 0 warning。动了 Rust 还要跑 `cargo test --lib`。

## 四、加完之后自查

```powershell
pnpm check                        # 类型和模板
pnpm icons                        # 加了图标才需要
```

然后在浏览器里确认：

- 侧栏里出现新条目，图标和角标正常，"待做"状态对
- 点进去 URL 是 `/tools/<id>`，标题和说明是注册表里写的
- 分区 Tab 能切，默认打开的是 `panel` 指定的那个
- 缩放窗口时侧栏会收成图标带，点一级能进第一项

`/tools/overview` 会自动跳到 `/`（总览就是首页，不做第二个入口）。
