## A. 养乐多（`yaku`）—— 照星铁编辑器那套

用户点名的两个病：**① 材质无法拖入 ②"必须选完了才能改"就是很垃圾的操作**。

### A1. 界面骨架

```
┌ 顶部：选模型目录 / 选渲染包 ────────────────────────────────┐
├──────────────┬──────────────────────────────┬──────────────┤
│ 左：文件与筛选 │ 中：要写的文件（一行一份）      │ 右：参数检查器 │
│ · 搜索框      │ · 每行：域 / 改了 N 项 / 缺 N 项 │ · 始终在这    │
│ · 分组列表    │ · 点一行＝把右边切到这份文件    │ · 点哪个改哪个 │
│ · 显示全部参数 │                              │ · 常用/完整两档 │
└──────────────┴──────────────────────────────┴──────────────┘
└ 底部固定条：N 份待写入 · 合计改了 N 项 ──────[确认写入 N 份]┘
```

**机制（这是用户骂的那条的解法）**：右栏参数**一直摆在那儿**，左栏与中栏只负责**筛选与导航** ——
**点哪个参数就改哪个，不存在"必须先选定某一行"的前置门槛**；中栏点一行只是**把右栏切到那份文件**，
不改也是允许的。**参数默认只显示常用项**（来源 / 纹理 / 材质 0 / 全局强度），需要时点「显示全部参数」展开。

### A2. 材质拖入

- **从窗口外**把 `.fx` / `.fxsub` 拖到**任意一行**上 → 直接给那一行挂上（行内落点面积小，会赢过大卡片的落点）；
- 拖到**卡片空白处** → 走"整批挂同一份"的默认动作（并提示做了什么）；
- 每行右侧另有「选…」按钮（键盘用户与拖不动时的退路）。

### A3. 用户只需做哪一步

选模型目录 → （渲染包已记住）→ **只改想改的那几个参数** → 底部「确认写入」。
不需要"先选文件再改参数"，不需要一份份点。

## B. ikClut 调色 —— 原图 / 调色后

用户原话："**原图 / 调色后显示图片的区域要原图和调色后的图都可以缩放拖动**"。

### B1. 界面对比区

```
┌─────────────── 原图 ───────────────┬────────────── 调色后 ──────────────┐
│  [滚轮缩放 10%–1200%]              │  [滚轮缩放 10%–1200%]              │
│  [按住左/中键拖动平移]              │  [按住左/中键拖动平移]              │
│  [一键重置]                        │  [一键重置]                        │
└────────────────────────────────────┴────────────────────────────────────┘
  两边**各自可缩放、可拖动**；另有「同步缩放/同步平移」开关（默认开）
  视图模式：调色后 / 调色前 / 前后对比 / 快照A / 快照B
```

### B2. 参数区（照"可折叠面板 + 响应式标签面板"）

`基本 / 曲线 / 色轮 / HSL / LOG / 变形 / LUT` —— **一排标签按钮，按可用宽度自动换列**，
点哪个标签就显示哪一组参数（**固定板块，不再往下堆**）。

### B3. 用户只需做哪一步

拖入参考图 → 在标签间切模式、拖参数 → 两边视图各自看细节（滚轮缩放、拖动平移）→ 导出。
