## 一、这一轮（2026-10-06）改了什么

### 1. 拖放选目录也要算"打开工程"（用户原话："拖拽选择时也需要触发这个变化"）

**原来的毛病**：选目录那条路会记最近工程 + 顶栏那颗 `当前工程`，因为页面调的是
`pickFolder('批量提取', '/tools/channels?panel=pipeline')` —— **记录挂在那个标签参数上**。
而拖文件夹进来走的是落点，**压根不经过 `pickFolder`**。于是同一个目录：
点按钮选它顶栏会变，拖进来不变。

**改法（一条出口）**：

| 地方 | 做了什么 |
|---|---|
| `src/lib/io.ts` | 新增 `记工程目录(path, label, href)`；`pickFolder` 也改走它 |
| `src/lib/dropzones.svelte.ts` | `DropZone` 加可选字段 `记?: { label; href }` |
| `src/lib/dirdrop.ts` | `接目录` 的参数改成 `(p)=>void` 或 `{收, label?, href?}`；把 `记` 塞进登记的那个 zone 对象（`update` 里改的是**同一个对象**，别另造） |
| `src/lib/drag-dom.ts` | 新增 `记成工程(zone, path)`；**原生**与 **HTML5** 两条 `dir` 落点分支都调 |
| 六处落点声明 | 都补上了 `label` / `href`（见下） |

补了 `记` 的六处（值跟同页 `pickFolder` 那一套**逐字对齐**，不然点按钮和拖进来会显示成两个名字）：

- `channels/Pipeline.svelte` → `批量提取` / `/tools/channels?panel=pipeline`
- `channels/Channels.svelte` → `整个目录批处理` / `/tools/channels?panel=batch`
- `ilm/Ilm.svelte` → `配对检查` / `/tools/ilm?panel=pairing`
- `glitch/Glitch.svelte` → 按当前栏给 `乱码批处理` / `.fx 注释` / `名字还原` / `日文乱码修复`
- `yaku/Yaku.svelte` → `养乐多上材质` / `/tools/yaku?panel=match`
- `ray/Ray.svelte` → `Ray 配置` / `/tools/ray?panel=conf`（只有 `d.dir` 那些才记）

**量具**：`tmp/拖材质链.test.mjs` 第 10 节（**58 通过 / 0 失败**）。它走的是真
`bringIn` + 真原生事件，正反两面都钉住了：
拖目录进来 → 报一次，标签/href 跟着落点走；**没带 `记` 的落点照样收下目录、但一条都不许记**
（导出目录那类不是工程）。

### 2. 顶栏「当前工程」（上一轮开的头，这一轮接着用）

`src/lib/recent.svelte.ts`：

- `当前工程` 是 `$state` 对象 `{path, name}`（`const` 声明的 `$state` 不能再整个赋值，所以改字段）
- `remember(path,label,href)` 里顺手 `设当前工程(path)`；初值取 `recent[0]`（刷新后不假装没开过）
- `⑨` 走的是 `.pmm`/`.emm` 两个文件、不经过选目录，所以 `Migrate.svelte` 自己用
  `报当前工程(pmm, 工程名(当前项))` 报一下（挂在 `pmm` 的 `$effect` 上，**拖进来也覆盖**）

**跳转别的功能 / 刷新时它怎么变**：**切页不变**（模块级状态，跟着"手上这个工程"走，
跟你翻到哪一页无关）；**刷新之后还在**，因为初值取 `recent[0]`。
只有两种情况会改：**又在某处选/拖了一个新目录**、或 `forget()`/`clearAll()` 把工程从列表删了。

**已量**（`tmp\probe-工程状态-顶栏与状态栏.mjs`，**18 过 0 红**）：干净状态两处都说"没有"；
塞一条最近工程 + **真 `Page.reload`** 之后，顶栏与状态栏都显示工程名、点变亮、title 是全路径；
**切页之后两处都不变**。

### 3. 状态栏（用户："而且状态栏的刷新重置需要考虑"）

跟顶栏同一类毛病，**位置在底部**，上一轮修顶栏时漏了：

| 毛病 | 改法 |
|---|---|
| 中段是**写死的两个字**（`就绪 · 工程未载入`），选了工程也不会变 | 接 `当前工程`（跟顶栏同一个来源）；没工程时灰点 +「未载入工程」，有工程亮蓝点 + 名字，全路径在 title |
| 那颗「重新开始统计」**不清柱子**：帧时间那 20 根柱子是组件本地数组（`hist`/`bars`），`resetPerf()` 碰不到它 —— 按下去数字清了、**柱子还留着刚才的尖峰**，等于没重置 | `perf.svelte.ts` 加 `perf.gen`（重置代数），`resetPerf()` 里 `+1`；`StatusBar` 盯代数换代，换代就把柱子清平 |

`perf.nodes` / `heapMB` **故意不清** —— 它们 1~5 秒自己会重采，清成 0 反而显示一个假数。

**已量 + 破坏性试验**：同一个探针的丁节 —— 按完按钮 20 根柱子全回 8% 底线；
把换代判定改成 `if (false && …)` 再跑，那条立刻变红（柱高 `[…,98,100,100,100,100,8]`）。

- **改文本文件只用 read / edit / write 工具**，绝不用 PowerShell 的 `Set-Content` / `Out-File`

- **别用 PowerShell 管道匹配中文**：`git ls-files | Select-String '开发者指南'` 匹配不上，
  我因此以为文件没提交。换成 git 自己的 pathspec。同理 `Get-Content` 显示中文文件会乱码，
  那不是文件坏了 —— 判断编码要用**字节**量（`dist\说明.txt` 我据此误判过一次 GBK）。

  扫语料时**排除 `测试效果\`**。`D:\MMD模型动作\模型\{…}` 只读。
