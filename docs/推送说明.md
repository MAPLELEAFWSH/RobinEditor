# 推到 GitHub 与 Gitee

仓库已经初始化好了，两个远端也配好了：

```
github  https://github.com/MAPLELEAFWSH/RobinEditor.git
gitee   https://gitee.com/mapleleafwsh/robin-editor.git
```

**这一台机器上没有凭据（没有 `credential.helper`、没有 SSH key、没有 `gh` CLI），
所以最后那一下 push 由你自己敲。**

## 我从这台机器上量到的（真客户端，不是 HEAD 探测）

```powershell
git ls-remote --heads gitee      # 退出码 0，无输出 → 通，而且仓库是空的（首推正是要这样）
git ls-remote --heads github     # fatal: Connection timed out after 300043 milliseconds
```

- **Gitee 通**，仓库已存在且是空的 —— 直接推就行。
- **GitHub 连不上**：是**连接**超时（300 s 都没建起来），不是认证失败。
  这台机器大概没走代理。要么开代理，要么换个网络推。
  注意 `Invoke-WebRequest -Method Head` 那种探测**不能用来判断通不通**（对很多站都超时，
  但实际是通的）—— 上面这两条是用 `git` 自己跑的。

## 先确认两个远端仓库已经建好

两边都**建成空仓库**（不要勾 README / .gitignore / LICENSE，勾了会跟本地历史冲突，
推的时候要 `--force` 或者先 pull 合并）。

- GitHub：<https://github.com/new> → 名字 `RobinEditor`，**不勾** Add a README
- Gitee：<https://gitee.com/projects/new> → 名字 `robin-editor`，**不勾** 使用 Readme 初始化

## 推（三条命令）

```powershell
cd E:\deepseek-harness\RobinEditor

git push -u github main
git push -u gitee main
```

第一次推会弹认证：

- **GitHub**：浏览器弹窗选 "Sign in with your browser"，或者贴一个
  **Personal Access Token**（Settings → Developer settings → Personal access tokens →
  Fine-grained，勾 `Contents: Read and write`）当密码用。**GitHub 早就不收账号密码了。**
- **Gitee**：直接输账号密码就行；开了两步验证的话用**私人令牌**。

想让它记住、以后不用再输：

```powershell
git config --global credential.helper manager    # Windows 凭据管理器
```

## 以后同步两边

```powershell
git push github main
git push gitee  main
```

或者一次推两个：

```powershell
git remote set-url --add --push github https://github.com/MAPLELEAFWSH/RobinEditor.git
git remote set-url --add --push github https://gitee.com/mapleleafwsh/robin-editor.git
git push github main          # 这一下会把两个远端都推了
```

（那样以后只看得到一个叫 `github` 的远端，好处是一条命令推两家，坏处是它们可能一成一败。
**两个远端各自推更清楚**，推荐。）

## 仓库里有什么、没什么

`.gitignore` 已经按体积和版权排掉了这些，**别手动 `git add -f` 加回来**：

| 排掉的 | 为什么 |
|---|---|
| `dist/*.exe`、`dist/*.msi` | 构建产物，十几 MB 且每次构建都变。`dist/` 里的 `.txt` 留着了 |
| `src-tauri/target/` | Rust 构建目录，**11 GB** |
| `tmp/chrome-audit/` | CDP 探针用的 Chrome 用户目录，**190 MB** |
| `tmp/ilmcheck/data/` | ⑤ 探针从**第三方素材**转储的原始像素，**136 MB，不许发布** |
| `tmp/素材-*.png` | 从语料复制的**游戏贴图**，第三方素材 |
| `tmp/ripple/*.png` | 涟漪探针截图，跑一次 `tools/cdp-ripple-probe.mjs` 就重新出 |
| `build/`、`.svelte-kit/`、`node_modules/` | 构建 / 依赖 |
| `参考工具样本/` | 研究用的第三方包，本来就在仓库外 |

**当前收进仓库的：562 个文件、约 12 MB。**

> `tmp/素材-②真图.png` 被排掉了，但 `tmp/probe-②原分辨率.mjs` 和
> `tmp/量-②真图编码.mjs` 要用它。要在本地跑那两条探针，自己从语料拷一份过去。

## 许可证

`LICENSE` 是 **MIT**（跟 `package.json` 里的 `license` 字段一致）。
**它只覆盖本仓库自己的代码** —— 仓库里不含也不分发任何第三方渲染包或工具
（Ray-mmd / 养乐多 / ikClut / msToon 等），也没复制它们的代码。
提交历史里也没有。详见 `docs/来源与边界.md`。

如果这个仓库要公开，**先确认 `PROGRESS.md` 和 `docs/` 里没有你不方便公开的东西** ——
那些文档写得很细，里面有不少来自你自己素材的实测数字和路径。
